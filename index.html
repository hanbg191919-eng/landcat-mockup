LANDCAT

랜드캣 화면 목업

길고양이를 동네 랜드마크로 등록하고 함께 지켜보는 서비스입니다. 같은 서비스를 웹과 앱 두 벌로 그렸습니다. 색·활자·문체 규칙은 두 벌이 같고, 플랫폼 때문에 달라지는 것만 다릅니다. 지도는 카카오·네이버 약관 확인 전이라 실제 타일이 아닌 자리표시이고, 사진은 전부 회색 블록입니다.

색
남색 #12243D
강조 노랑 #FFC800
배경 #F7F8F9
구분선 #EEF0F2
활자
Gothic A1 — 제목 800, 본문 400~500
IBM Plex Mono — 순수 숫자에만
라벨·이름·주소에는 모노스페이스를 쓰지 않습니다
간격
8px 그리드 · 좌우 여백 20px(앱) / 24~32px(웹)
카드·버튼 모서리 8px, 전면 바 0px
터치 영역 44px(앱) / 컨트롤 40px(웹)
원칙
노랑은 화면당 최대 두 곳
로마자 라벨 없음 (LANDCAT · LIVE 예외)
장식용 좌표·조회수·0 채운 숫자 없음

앱 버전 390 × 844 · React Native WebView

웹 버전 1440 × 900 · Vite + TypeScript

미채택 시안 고르지 않은 안. 참고용으로 남김

등록 흐름 — 지도 홈에서 위치 선택 → 카메라 → 등록 정보 → 프로필. 카메라 화면에 앨범 진입점이 없습니다. 앨범에서 아무 사진이나 올릴 수 있으면 목격 기록을 믿을 수 없기 때문입니다.

웹에 카메라 화면이 없는 것은 의도입니다 — 등록은 앱에서만 하고, 웹에서는 그 자리를 '등록 안내' 화면이 대신합니다. 웹에서 할 수 있는 것은 둘러보기 · 좋아요 · 댓글 · 커뮤니티 글쓰기입니다.

아직 정해지지 않은 것 — 첫 화면 구조(지도 우선 vs 피드 우선), 지도 API(카카오 vs 네이버).
