# 랜드캣 화면 목업

길고양이를 동네 랜드마크로 등록하고 함께 지켜보는 서비스의 화면 목업입니다.

**보기 → https://hanbg191919-eng.github.io/landcat-mockup/**

## 담긴 것

| 구분 | 규격 | 화면 |
|---|---|---|
| 웹 버전 | 1440 × 900 | 지도 홈 · 고양이 프로필 · 라이브 · 커뮤니티 · 마이페이지 · 신고 · 등록 안내 |
| 앱 버전 | 390 × 844 | 지도 홈 · 카메라 · 등록 정보 · 고양이 프로필 · 신고 · 라이브 · 커뮤니티 · 마이페이지 |
| 미채택 시안 | — | 앱 지도 홈 대안 · 야간관측 · 활자대장 · 구조 시안 A · 구조 시안 B |

## 디자인 시스템

- **색** 남색 `#12243D` / 강조 노랑 `#FFC800` / 배경 `#FFFFFF` `#F7F8F9` / 본문 `#1A1D21` / 보조 `#6E7781` / 구분선 `#EEF0F2` / 지도 `#E8EBED` `#DDE1E4`
- **활자** Gothic A1 (제목 800, 본문 400~500). IBM Plex Mono는 좋아요 수 같은 순수 숫자에만 쓰고 라벨·이름·주소에는 쓰지 않습니다.
- **간격** 8px 그리드. 좌우 여백 20px(앱) / 24~32px(웹). 카드·버튼 모서리 8px, 전면 바 0px.
- **터치 영역** 44px(앱) / 컨트롤 40px(웹)
- **원칙** 노랑은 화면당 최대 두 곳. 로마자 라벨을 쓰지 않습니다(서비스명 `LANDCAT`, 상태 배지 `LIVE` 예외). 장식용 좌표·조회수·0을 채운 숫자를 쓰지 않습니다.

## 웹과 앱이 다른 점

앱에서 위아래로 쌓였던 것을 웹에서는 좌우로 펼쳤습니다. 지도 홈은 목록·지도·상세 3단, 프로필은 사진과 정보 2단, 라이브는 플레이어 옆에 채팅 패널, 커뮤니티는 본문 옆에 사이드바, 마이페이지는 카드 4열(앱은 2열)입니다. 신고는 하단 시트가 아니라 화면 중앙 모달입니다.

웹에 카메라 화면이 없는 것은 의도입니다. 등록은 카메라로 그 자리에서 찍은 사진만 받기 때문에 웹에서는 지원하지 않고, 그 자리를 등록 안내 화면이 대신합니다. 웹에서 할 수 있는 것은 둘러보기 · 좋아요 · 댓글 · 커뮤니티 글쓰기입니다.

## 참고

- 지도는 카카오 · 네이버 약관 확인 전이라 실제 타일이 아닌 자리표시입니다. 두 곳 모두 로고와 저작권 표기가 의무라 그 자리를 비워 뒀습니다.
- 사진은 전부 회색 블록입니다.
- 아직 정해지지 않은 것: 첫 화면 구조(지도 우선 vs 피드 우선), 지도 API(카카오 vs 네이버).
